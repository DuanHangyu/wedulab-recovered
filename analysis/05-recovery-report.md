# WeduLab 恢复交付

已恢复可运行、可编辑、可构建的生产客户端：首页、22 个实验、六种语言、原三维场景与着色器、公式、字体、地理数据、反馈和管理前端。反馈与访问统计后端按公开接口重建。

## 启动

进入相邻 `../project/`，使用 Node.js 24 或更新版本：

```sh
npm run dev
```

打开 http://127.0.0.1:4174/?lang=zh-CN 。无需安装前端依赖。实验在 `src/labs/<实验名>/Page.js`，首页在 `src/home/`，样式在 `public/assets/`。

```sh
npm run build
npm start
npm test
```

反馈和统计存入本地 SQLite。复制 `.env.example` 为 `.env` 并设置自己的 `ADMIN_PASSWORD`，重启后可登录 `/admin/analytics`。详细说明见 `../project/README.md`。

## 恢复边界

原部署没有源码映射，原始 TS/JSX、类型、变量名、注释、Git 历史和构建配置不能精确找回。本工程保留生产 JavaScript 实际逻辑，格式化后按模块组织，并重新命名可确认的组件和导入。

原服务端代码、账号密码、历史反馈/访问数据库和 IP 定位服务不在公开部署中。`server/` 是接口兼容重建，没有伪造原统计。`npm audit` 不覆盖已经打包的第三方库。

字体已本地化；Cloudflare 第三方信标移除，业务访问事件由本地接口处理。原部署 JS/CSS/HTML/图片与数据备份保持原始字节，补存字体提供本地路径。没有发布、推送或修改线上网站。
