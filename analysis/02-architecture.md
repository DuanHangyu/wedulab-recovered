# 恢复后的执行链

## 浏览器入口
输入是路径、`lang` 查询参数、实验 hash 和浏览器保存的语言。原入口通过语言归一化选择词典、匹配 22 个 lazy 路由、加载路由 CSS、挂载对应 React 页面。恢复工程把路由挂载移到 `src/main.js`，共享库位于 `src/core/runtime.js`，页面进口从原入口调整为共享库，保持原导出别名。

## 实验初始化
每个页面输出原有 DOM，并在 React effect 中创建画布、场景、模型与事件处理。原 initializer 和数据数组保持原逻辑。动态资源包括地球纹理、地理边界和气候数据，已经保存为本地资源。数学页面的 KaTeX 字体和引擎同样保留。

## 状态与动画
输入为指针、滚轮、键盘、面板控件、章节选择、经过的时间。原控制器修改模型状态，原 RAF/定时器更新模拟、绘制三维/二维画布并刷新 DOM 文本。恢复未替换模拟求解器、着色器、相机或随机模型。数值与动作不能只凭静态截图验收。

## 外部接口
每次访问发送同源 analytics event；反馈表单发送同源 feedback。原后端没有公开部署源码，当前 Node/SQLite 是根据前端契约重建的兼容实现。原第三方 Cloudflare 统计脚本已从可编辑工程去除，原基线保持原 HTML。字体改为保存的本地 Google Fonts 文件，保持家族/字重。

## 可恢复与不可恢复
公开客户端生产代码可恢复；原 TS 类型、注释、源码目录、源码映射和服务端历史状态无法从公开内容证明。运行效果通过原始模块保留和源站/基线/可编辑工程对照验证。
