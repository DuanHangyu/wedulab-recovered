章节内容

光的反射定律

激光沿量角盘射向平面镜的中心 O。过入射点作垂直于镜面的法线（盘上的竖直虚线），入射光线与法线的夹角叫入射角 i，反射光线与法线的夹角叫反射角 r。

r = i

反射光线、入射光线和法线在同一平面内，反射光线和入射光线分居法线两侧。

拖动激光笔绕盘转动，或用滑块改变入射角，按记录数据保存每组 i 和 r。让光逆着反射光射入，会沿原入射光射出——光路可逆。

平面镜成像

用透明的玻璃板代替平面镜：既能看到点燃的蜡烛 A 在玻璃后面的像，又能看到玻璃后面的蜡烛 B。

拖动未点燃的蜡烛 B，直到从各个角度看它都和 A 的像完全重合，好像 B 也被点燃了一样。这时量一量：

像距 = 物距 像高 = 物高

平面镜成正立、等大的虚像，像与物关于镜面对称。打开光路可以看到：反射光线的反向延长线交于像点，像点处并没有真实的光会聚，所以是虚像——放一块光屏在那里，屏上什么也接收不到。

光的折射

激光从空气斜射入半圆形玻璃砖的平面中心。光进入玻璃后偏向法线，折射角 r 小于入射角 i；从弧面射出时沿半径方向，不再偏折，便于读数。

多测几组 i、r 会发现 i 与 r 并不成正比，而是它们的正弦成正比——折射定律：

n = sin i / sin r

n 叫这种介质的折射率。在数据坞中画出 sin i - sin r 图像，斜率就是 n。换成水（1.33）、钻石（2.42）比较。

全反射与光纤

光从玻璃射向空气时，折射角大于入射角。增大入射角，折射光越来越靠近界面、越来越暗，反射光越来越亮。

当入射角达到临界角 C 时折射角为 90°，再增大入射角，折射光完全消失，只剩反射光——这就是全反射：

sin C = 1 / n

玻璃的临界角约 41°，钻石只有 24°，所以钻石格外闪亮。切换到光纤：光在纤芯与包层的界面上不断全反射，即使光纤弯曲，光也能从另一端射出。

棱镜色散

一束白光穿过三棱镜后，在光屏上展开成红、橙、黄、绿、蓝、靛、紫的彩色光带——光的色散。牛顿用这个实验证明：白光是由各种色光混合而成的。

同一种玻璃对不同色光的折射率不同：紫光的折射率最大，偏折最多；红光最小，偏折最少。

改用单色的红色激光，经过棱镜后只偏折、不再分开。在后面加一块倒置的棱镜，各色光又重新会合成白光。

凸透镜成像规律

把蜡烛、凸透镜、光屏依次放在光具座上，烛焰、透镜、光屏的中心大致在同一高度。移动光屏直到屏上的像最清晰，读出物距 u 和像距 v。

· u > 2f：倒立、缩小的实像（照相机）· u = 2f：倒立、等大的实像· f < u < 2f：倒立、放大的实像（投影仪）· u = f：不成像· u < f：正立、放大的虚像（放大镜），光屏上接收不到

1/u + 1/v = 1/f

记录多组 u、v，在数据坞中画 1/u - 1/v 图像，截距就是 1/f。

眼睛与视力矫正

眼睛像一架照相机：晶状体相当于凸透镜，视网膜相当于光屏。睫状体改变晶状体的厚薄（焦距），使远近不同的物体都能在视网膜上成清晰的像。

近视眼：眼球前后径过长（或晶状体太厚），远处物体的像落在视网膜前方，看不清远处。用凹透镜使光线发散一些来矫正。

远视眼：像落在视网膜后方，看不清近处。用凸透镜矫正。

眼镜度数 = 光焦度 × 100 = 100 / f（f 以 m 计）

双缝干涉

激光照到相距很近的两条狭缝上，两缝相当于两个相干光源。两列光波在光屏上叠加：光程差为波长整数倍处加强，出现亮纹；为半波长奇数倍处减弱，出现暗纹。

Δx = L λ / d

相邻亮纹的间距 Δx 与屏距 L、波长 λ 成正比，与缝距 d 成反比。台面上的彩色波纹是两列波叠加的示意（波长已放大）。

用测量头测出 n 条亮纹的总宽度，就能算出光的波长。换成白光，中央是白色亮纹，两侧是彩色条纹。

单缝衍射与光栅

光通过很窄的单缝后，屏上出现中央宽而亮、两侧窄而暗的条纹——光的衍射。缝越窄，中央亮纹越宽，衍射越明显。

中央亮纹半宽 x₁ = L λ / a

与双缝干涉条纹（等间距）不同，单缝衍射条纹中央亮纹的宽度是其他亮纹的两倍。

光栅有大量等间距的狭缝，主极大非常细锐明亮：d sinθ = kλ。用白光照射，各级出现彩色光谱，紫光偏折最小、红光最大——与棱镜正好相反。

薄膜干涉

把铁丝圈从肥皂液中提起，竖直放置。膜在重力作用下上薄下厚。光在膜的前后两个表面反射，两列反射光叠加：厚度 t 满足 2nt = kλ 附近相互减弱，(k + ½)λ 附近相互加强。

同一厚度对应同一种颜色，所以出现水平的彩色条纹；膜不断变薄，条纹向下移动，最上方变成黑色，随后膜破裂。用黄色钠光照射，只看到明暗相间的黄黑条纹。

牛顿环：平凸透镜压在平板玻璃上，空气膜厚度 t = r²/2R，形成内疏外密的同心圆环：

rk = √(kλR)

光的偏振

光是横波。自然光在垂直于传播方向的平面内沿各个方向振动；通过偏振片后，只剩沿透振方向振动的光——线偏振光，强度减半。

再用第二块偏振片（检偏器）观察：转动检偏器，透射光强周期性变化，两透振方向垂直时完全消光。马吕斯定律：

I = I₀ cos²θ

液晶显示屏：两块正交的偏振片之间夹着扭曲的液晶，液晶把偏振方向转 90°，光能通过（亮）；加电压后液晶分子竖直排列不再旋转，光被挡住（暗）。
