章節內容

電子雲

我們無法同時確定電子的位置和速度，只能說電子在某處出現的概率有多大。

舞臺上每一個點都是一次“測量”記錄下的電子位置。記錄得越多，點的疏密就越清楚地顯示出概率密度 |ψ|²——這就是電子雲。

點密的地方電子出現的概率大，並不是那裡有很多電子。

軌道形狀

把電子出現概率為 90% 的區域圈起來，得到的曲面就是常說的原子軌道形狀。

s 軌道是球形；p 軌道是啞鈴形，沿 x、y、z 三個方向各一個；d 軌道多為四葉花瓣形，共 5 個。

暖色和冷色分別表示波函數 ψ 的正、負相位，不是電荷。相位決定了原子之間能否成鍵。每一層發光的殼層都是一個等概率面，越往裡電子出現的概率密度越大。

徑向分佈與節面

徑向分佈函數 P(r) = r²R² 表示電子出現在半徑 r 處薄球殼內的概率。

1s 的峰值恰好在 r = a₀（玻爾半徑）。2s、3s 在峰之間出現概率為零的球面，叫徑向節面，共 n − l − 1 個。

截面圖中的暗色圓環就是徑向節面，暗色直線是角節面。

能級與構造原理

多電子原子中，電子按以下規則逐個填入軌道：

能量最低原理：先填能量低的能級。注意 4s 比 3d 先填。

泡利原理：一個軌道最多容納 2 個電子，且自旋相反。

洪特規則：同一能級的幾個軌道，電子先分佔不同軌道，且自旋平行。

電子排布

點擊週期表中的元素，查看它的電子排布式和軌道表示式。舞臺上顯示價層電子的電子雲：藍色為 s，橙色為 p，紫色為 d。

量子數

三個量子數確定一個原子軌道：

n 主量子數，決定能層與大小；l 角量子數（0 ≤ l ≤ n − 1），決定形狀；m 磁量子數（−l ≤ m ≤ l），決定空間取向。

節面總數 = n − 1，其中角節面 l 個、徑向節面 n − l − 1 個。
