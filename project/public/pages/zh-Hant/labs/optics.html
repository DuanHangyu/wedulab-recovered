暗室光學實驗台：雷射、量角盤、半圓磚、三稜鏡、光具座與光屏，12 個課題涵蓋反射與折射、全反射與光纖、色散、凸透鏡成像、眼睛與視力矯正、雙縫干涉、繞射與光柵、薄膜干涉和偏振。

學科：物理 · 適用學段：國中、高中 · 知識點：折射定律、凸透鏡成像、雙縫干涉、光的偏振

章節內容

光的反射定律

雷射沿量角盤射向平面鏡的中心 O。過入射點作垂直於鏡面的法線（盤上的豎直虛線），入射光線與法線的夾角叫入射角 i，反射光線與法線的夾角叫反射角 r。

r = i

反射光線、入射光線和法線在同一平面內，反射光線和入射光線分居法線兩側。

拖動雷射筆繞盤轉動，或用滑桿改變入射角，按記錄資料儲存每組 i 和 r。讓光逆著反射光射入，會沿原入射光射出——光路可逆。

平面鏡成像

用透明的玻璃板代替平面鏡：既能看到點燃的蠟燭 A 在玻璃後面的像，又能看到玻璃後面的蠟燭 B。

拖動未點燃的蠟燭 B，直到從各個角度看它都和 A 的像完全重合，好像 B 也被點燃了一樣。這時量一量：

像距 = 物距 像高 = 物高

平面鏡成正立、等大的虛像，像與物關於鏡面對稱。打開光路可以看到：反射光線的反向延長線交於像點，像點處並沒有真實的光會聚，所以是虛像——放一塊光屏在那裡，屏上什麼也接收不到。

光的折射

雷射從空氣斜射入半圓形玻璃磚的平面中心。光進入玻璃後偏向法線，折射角 r 小於入射角 i；從弧面射出時沿半徑方向，不再偏折，便於讀數。

多測幾組 i、r 會發現 i 與 r 並不成正比，而是它們的正弦成正比——折射定律：

n = sin i / sin r

n 叫這種介質的折射率。在資料塢中畫出 sin i - sin r 圖像，斜率就是 n。換成水（1.33）、鑽石（2.42）比較。

全反射與光纖

光從玻璃射向空氣時，折射角大於入射角。增大入射角，折射光越來越靠近界面、越來越暗，反射光越來越亮。

當入射角達到臨界角 C 時折射角為 90°，再增大入射角，折射光完全消失，只剩反射光——這就是全反射：

sin C = 1 / n

玻璃的臨界角約 41°，鑽石只有 24°，所以鑽石格外閃亮。切換到光纖：光在纖芯與包層的界面上不斷全反射，即使光纖彎曲，光也能從另一端射出。

稜鏡色散

一束白光穿過三稜鏡後，在光屏上展開成紅、橙、黃、綠、藍、靛、紫的彩色光帶——光的色散。牛頓用這個實驗證明：白光是由各種色光混合而成的。

同一種玻璃對不同色光的折射率不同：紫光的折射率最大，偏折最多；紅光最小，偏折最少。

改用單色的紅色雷射，經過稜鏡後只偏折、不再分開。在後面加一塊倒置的稜鏡，各色光又重新會合成白光。

凸透鏡成像規律

把蠟燭、凸透鏡、光屏依次放在光具座上，燭焰、透鏡、光屏的中心大致在同一高度。移動光屏直到屏上的像最清晰，讀出物距 u 和像距 v。

· u > 2f：倒立、縮小的實像（照相機）· u = 2f：倒立、等大的實像· f < u < 2f：倒立、放大的實像（投影機）· u = f：不成像· u < f：正立、放大的虛像（放大鏡），光屏上接收不到

1/u + 1/v = 1/f

記錄多組 u、v，在資料塢中畫 1/u - 1/v 圖像，截距就是 1/f。

眼睛與視力矯正

眼睛像一架照相機：晶狀體相當於凸透鏡，視網膜相當於光屏。睫狀體改變晶狀體的厚薄（焦距），使遠近不同的物體都能在視網膜上成清晰的像。

近視眼：眼球前後徑過長（或晶狀體太厚），遠處物體的像落在視網膜前方，看不清遠處。用凹透鏡使光線發散一些來矯正。

遠視眼：像落在視網膜後方，看不清近處。用凸透鏡矯正。

眼鏡度數 = 屈光度 × 100 = 100 / f（f 以 m 計）

雙縫干涉

雷射照到相距很近的兩條狹縫上，兩縫相當於兩個相干光源。兩列光波在光屏上疊加：光程差為波長整數倍處加強，出現亮紋；為半波長奇數倍處減弱，出現暗紋。

Δx = L λ / d

相鄰亮紋的間距 Δx 與屏距 L、波長 λ 成正比，與縫距 d 成反比。台面上的彩色波紋是兩列波疊加的示意（波長已放大）。

用測量頭測出 n 條亮紋的總寬度，就能算出光的波長。換成白光，中央是白色亮紋，兩側是彩色條紋。

單縫繞射與光柵

光通過很窄的單縫後，屏上出現中央寬而亮、兩側窄而暗的條紋——光的繞射。縫越窄，中央亮紋越寬，繞射越明顯。

中央亮紋半寬 x₁ = L λ / a

與雙縫干涉條紋（等間距）不同，單縫繞射條紋中央亮紋的寬度是其他亮紋的兩倍。

光柵有大量等間距的狹縫，主極大非常細銳明亮：d sinθ = kλ。用白光照射，各級出現彩色光譜，紫光偏折最小、紅光最大——與稜鏡正好相反。

薄膜干涉

把鐵絲圈從肥皂液中提起，豎直放置。膜在重力作用下上薄下厚。光在膜的前後兩個表面反射，兩列反射光疊加：厚度 t 滿足 2nt = kλ 附近相互減弱，(k + ½)λ 附近相互加強。

同一厚度對應同一種顏色，所以出現水平的彩色條紋；膜不斷變薄，條紋向下移動，最上方變成黑色，隨後膜破裂。用黃色鈉光照射，只看到明暗相間的黃黑條紋。

牛頓環：平凸透鏡壓在平板玻璃上，空氣膜厚度 t = r²/2R，形成內疏外密的同心圓環：

rk = √(kλR)

光的偏振

光是橫波。自然光在垂直於傳播方向的平面內沿各個方向振動；通過偏振片後，只剩沿透振方向振動的光——線偏振光，強度減半。

再用第二塊偏振片（檢偏器）觀察：轉動檢偏器，透射光強週期性變化，兩透振方向垂直時完全消光。馬呂斯定律：

I = I₀ cos²θ

液晶顯示螢幕：兩塊正交的偏振片之間夾著扭曲的液晶，液晶把偏振方向轉 90°，光能通過（亮）；加電壓後液晶分子豎直排列不再旋轉，光被擋住（暗）。
