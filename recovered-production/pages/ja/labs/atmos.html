大気の運動の概観

大気の運動のエネルギーの源は太陽放射です。地表の加熱のむらが空気の鉛直運動と、同じ水平面上の気圧差を生み、熱循環を作ります。全球の規模では、さらに地球の自転の影響が重なり、三つの循環と七つの気圧帯、六つの風帯が形成されます。

三次元の地球はドラッグして回転でき、ホイールで拡大縮小できます。地球の縁の光の環は南北方向の循環の断面で、いつもこちらを向いています。

熱循環の原理

熱循環は、地面の加熱のむらによってできる空気の循環で、大気の運動のうち最も単純な形です。手順を追って、どうできるかを見てみましょう：

熱 → 上昇 → 地表付近は低圧、上空は高圧冷 → 下降 → 地表付近は高圧、上空は低圧

等圧面は、高圧側で上に凸、低圧側で下に凹。

同じ地点では、地表付近と上空とで気圧の性質が逆になります。

水平方向では、空気はいつも高圧から低圧へ流れ。

鉛直方向では、地表付近の気圧はいつも上空より高くなります。「高圧」「低圧」は、同じ水平面と比べたときの呼び方です。

都市のヒートアイランド循環

都市は人口と工業が集中し、生産と生活から大量の廃熱が出ます。コンクリートやアスファルトの路面は熱を多く吸収し、緑地は少なく、市街の気温は郊外より高くなって都市のヒートアイランドができます。市街の空気は上昇し、郊外の空気は下降し、地表付近の風は郊外から市街へ吹きます。

地表付近：郊外 → 市街上空：市街 → 郊外。市街で上昇し、郊外で下降します。

大気汚染の重い工業はヒートアイランド循環の外。

都市の緑地は循環の内側、下降域の近くに置くと、市街へ向かう空気を浄化できます。

緑地や水面を増やし、明るい色の屋根を使うと、ヒートアイランドを弱められます。

海陸風

陸地の比熱は小さく、昇温も降温も海より速い。昼は陸地の気温が高く、地表付近に低圧ができ、風は海から陸へ吹きます。これが海風です。夜は陸地の冷え方が速く、気圧が海より高くなり、風は陸から海へ吹きます。これが陸風。

昼は海風 · 夜は陸風地表付近の風は、いつも、より冷たい（高圧の）側から、より暖かい（低圧の）側へ吹きます。

海風のおかげで、沿岸地域の夏の昼は比較的涼しく、空気は湿っています。

昔の漁師は「陸風に乗って朝に出航し、海風に乗って夕方に帰港した」といいます。

山谷風

昼は斜面の昇温が速く、斜面の上の空気は同じ高さの谷の上空より暖かくなります。空気は斜面に沿って上昇し、谷底の空気がそれを補います。これが谷風です。夜は斜面の降温が速く、冷たい空気が斜面を下って谷底へ流れ込みます。これが山風。

昼は谷風 · 夜は山風

夜は谷底の暖かく湿った空気が冷気に持ち上げられ、雲になって雨が降りやすく、山地には夜雨。

冷たい空気が谷底に積もると逆転層ができやすく、汚染物質が拡散しにくくなります。谷に大気汚染の重い工業を置くのは適しません。

単一循環

まず二つの仮定を置きます：地表は一様、地球は自転しない。赤道が最も熱せられ、空気は膨張して上昇し、上空を両極へ向かいます。両極では冷えて空気が収縮して下降し、地表付近を両極から赤道へ戻ります。南北の半球はそれぞれ一つずつ閉じた熱循環を作ります。

赤道：加熱 → 上昇 → 地表付近は低圧極：冷却 → 下降 → 地表付近は高圧

地球の縁の断面を見ると、粒子は赤道で上昇し、両極で下降します。

地表付近の気流は経線に沿って極から赤道へまっすぐ吹きます、東西方向への偏向はありません。

実際には地球は自転しているので、このような単一の循環は存在しません。次の節を見てください。

三つの循環

地球の自転が生み出すコリオリの力（転向力）（北半球は右向き、南半球は左向き）。赤道上空から極へ向かう気流は、およそ 30° 付近ですでに西風へ偏向し、空気が堆積して下降するため、単一の循環は三つの循環の輪。

ハドレー循環：赤道で上昇 → 上空は 30° へ → 下降 → 地表付近を赤道へ戻ります。

フェレル循環：30° で下降した気流の一部は高緯度へ向かい、60° 付近で極からの冷たい空気と出会って持ち上げられます。

極循環：極で冷却されて下降 → 地表付近は 60° へ → 上昇 → 上空を極へ戻ります。

気圧帯と風帯

三つの循環は地表付近に七つの気圧帯、六つの風帯を形成し、高圧と低圧が交互に並び、風帯は気圧帯のあいだに挟まれます。

赤道低圧 · 亜熱帯高圧 · 亜寒帯低圧 · 極高圧風は高圧から低圧へ吹き、「北は右、南は左」に偏向します。

季節移動

気圧帯と風帯は太陽直射点の移動に伴って動きます。北半球では、おおよそ夏は北へ、冬は南へ移り、移動の幅は緯度およそ 5～10 度です。

地中海性気候（大陸西岸のおよそ 30°–40°）：夏は亜熱帯高圧帯に支配され、暑く乾燥します。冬は偏西風帯に支配され、温和で雨が多くなります。左下の 38°N のリアルタイム判定を見てください。

サバナ気候：赤道低圧帯と貿易風帯が交互に支配し、乾季と雨季がはっきり分かれます。

海陸分布と季節風

実際の地球表面は海と陸が入り組んでいます。陸地は冬に冷たく夏に暑い、海洋は冬に暖かく夏に涼しいため、気圧帯は一つ一つの高気圧・低気圧の中心に切られ、季節風もここから生まれます。地球上に表示しているのは NCEP 再解析資料 1991–2020 年の、月平均の地表付近の風と海面気圧です。

ユーラシア大陸が冷えて、強大なアジア高気圧（モンゴル—シベリア高気圧）ができ、亜寒帯低圧帯を切断し、海洋上に残るのはアリューシャン低気圧とアイスランド低気圧。

中国東部では北西季節風が吹き、寒冷で乾燥します。南アジアでは北東季節風。

ユーラシア大陸が熱せられてアジア低気圧（インド低気圧）ができ、亜熱帯高圧帯を切断し、海洋上に残るのはハワイ高気圧とアゾレス高気圧。

中国東部では南東季節風が吹き、高温で雨が多くなります。南アジアでは南西季節風が吹きます。これは南半球の南東貿易風が赤道を越えたあと、右へ偏向したものです。

東アジアの季節風：海と陸の熱的性質の違い南アジアの季節風：海と陸の熱的性質の違い + 気圧帯・風帯の季節移動
