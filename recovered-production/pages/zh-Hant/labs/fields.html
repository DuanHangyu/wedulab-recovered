章節內容

電力線與等位面

點電荷周圍的電場 E = kQ/r²，多個電荷的電場按向量疊加。用電力線形象地描述電場：線上每點的切線方向就是電場方向，線的疏密表示電場大小。電力線從正電荷（或無窮遠）出發，終止於負電荷（或無窮遠），不相交、不封閉。

電位 φ = kQ/r 是純量，直接相加。電位相等的點連成等位線：

等位線處處與電力線垂直，沿電力線方向電位降低

拖曳電荷改變它們的位置，拖曳探針讀出任意一點的 E 和 φ。打開立體電位面：正電荷處是「山峰」，負電荷處是「深谷」，電力線就是「最陡的下坡方向」。

電力做功與電位能

把試探電荷 q 從 A 點移到 B 點，電力做的功

WAB = q (φA − φB) = q UAB

只與起點、終點的位置有關，與路徑無關——和重力做功一樣。所以可以定義電位能 Ep = qφ：電力做正功，電位能減少；做負功，電位能增加。

分別沿直線、折線、彎曲三條路徑移動 q，資料塢中的 W - s 曲線各不相同，終點處卻匯於同一點。拖曳 A、B 兩點，或者把試探電荷換成負電荷再試。

平行板電容器

兩塊彼此絕緣、靠得很近的平行金屬板構成平行板電容器。它的電容

C = εr S / (4πkd) = εrε0 S / d

充電後斷開電源，極板上的電荷量 Q 不變，由 U = Q/C 知：增大 d、減小正對面積 S，或抽出介電質，C 變小，靜電計指針偏角（U）變大。而板間電場 E = U/d = Q/(εrε0S) 與 d 無關。

若始終接在電源上，U 不變，改變 d 時 Q 和 E 隨之變化。記錄多組資料，C - 1/d 圖形是一條過原點的直線。

陰極射線管

陰極 K 被燈絲加熱後發射電子，經加速電壓 U₁ 加速：eU₁ = ½mv₀²。電子以 v₀ 垂直進入偏向電極（板長 L、間距 d），在電場中做類拋體運動，離開偏向板時的側移

y = qU₂L² / (2mdv₀²) = U₂L² / (4dU₁)

之後等速直線運動打到螢光幕上，好像從偏向板中點沿直線射出。偏移量與 U₂ 成正比，這就是示波器測電壓的原理。

在 X 偏向板上加鋸齒形的掃描電壓，電子束從左到右等速掃過螢幕；Y 板上加待測訊號，螢幕上就畫出訊號的波形。

磁力線

在玻璃板上均勻撒一層鐵粉，輕敲玻璃板，鐵粉被磁化後沿磁場方向排成一條條曲線；放上小磁針，靜止時 N 極的指向就是該點的磁場方向。

磁力線在磁鐵外部從 N 極出發回到 S 極，在內部從 S 極到 N 極，是封閉曲線。

電流也能產生磁場（厄斯特）。直導線的磁力線是一圈圈同心圓，用安培右手定則判斷方向：

直導線 B = μ₀I / (2πr)

環形電流和通電螺線管的磁場與條形磁鐵相似，螺線管內部是近似均勻的磁場。

安培力

把一根銅棒橫放在兩條水平金屬導軌上，置於 U 形磁鐵的兩極之間。接通電源，電流流過銅棒，銅棒受到安培力沿導軌滾動。

F = B I L

L 是導體在磁場中的有效長度（磁鐵越多，L 越長）。安培力的方向用左手定則判斷：伸開左手，讓磁力線垂直穿入手心，四指指向電流方向，拇指所指就是安培力的方向。

改變電流方向或者對調磁極，銅棒的運動方向都會反過來；同時改變兩者，方向不變。

勞倫茲力

運動電荷在磁場中受到勞倫茲力 F = qvB（v ⊥ B），方向由左手定則判斷（負電荷與正電荷相反）。勞倫茲力始終垂直於速度，不做功，只改變速度的方向。

勞倫茲力演示儀：亥姆霍茲線圈產生均勻磁場，玻璃泡內的稀薄氣體讓電子束的徑跡發光。電子垂直磁場射入時做等速圓周運動：

r = mv / (qB) T = 2πm / (qB)

傾斜電子槍，速度有平行於 B 的分量，徑跡變成螺旋線。

速度選擇器：電場與磁場互相垂直，只有 qE = qvB，即 v = E / B 的粒子能沿直線穿過狹縫。

質譜儀與迴旋加速器

質譜儀：離子經電壓 U 加速後從狹縫 S 垂直進入均勻磁場，做半個圓周運動打在照相底片上：

qU = ½mv² r = mv/(qB) = √(2mU/q) / B

電荷量相同的同位素，質量越大半徑越大，在底片上形成一條條譜線，r₁ : r₂ = √m₁ : √m₂。阿斯頓就是這樣發現了氖的同位素。

迴旋加速器：兩個 D 形盒置於均勻磁場中，縫隙間加交變電壓。粒子每次經過縫隙被加速一次，半徑越來越大，但週期 T = 2πm/(qB) 與速度無關，所以交變電壓的頻率可以固定。最終動能

Ek = q²B²R² / (2m)

只取決於 B 和 D 形盒半徑 R，與加速電壓無關。

電磁感應與冷次定律

穿過封閉迴路的磁通量發生變化，迴路中就產生應電流——電磁感應（法拉第）。感應電動勢

E = N ΔΦ / Δt

拖曳磁鐵插入、拔出線圈，檢流計指針偏轉；磁鐵不動時指針回零。插拔越快，偏轉越大。

冷次定律：應電流的磁場總要阻礙引起應電流的磁通量的變化——「來拒去留」。

導體棒在磁場中切割磁力線：E = BLv。應電流使棒受到與運動方向相反的安培力 F = B²L²v/R，在恆定拉力下棒最終等速運動。

交流發電機

矩形線圈在均勻磁場中繞垂直於磁場的軸等速轉動，ab、cd 兩邊切割磁力線，線圈中產生大小和方向都週期性變化的交流電。從中性面開始計時：

e = Em sin ωt Em = NBSω

線圈平面與磁場垂直的位置叫中性面：此時磁通量最大，但各邊不切割磁力線，電動勢為零；轉過 90°，磁通量為零，電動勢最大。每經過中性面一次，電流方向改變一次。

正弦交流電的有效值 E = Em / √2：讓交流電和直流電通過相同的電阻，相同時間內產生的熱量相等。

自由實驗

在實驗台上自由放置點電荷，在右半邊開啟一塊均勻磁場區，用粒子槍發射電子、質子或 α 粒子，觀察它們在電場和磁場中的軌跡（Boris 演算法逐步計算）。
